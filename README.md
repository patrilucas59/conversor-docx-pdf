# PDF Machine

Aplicação web fullstack para conversão de arquivos DOCX em PDF.

## Tecnologias

Frontend:
- React
- TypeScript
- Axios
- Vite

Backend:

- Node.js
- Express
- Multer
- LibreOffice

## Como rodar o projeto

### Backend

cd backend
npm install
npm run dev

### Frontend

cd frontend
npm install
npm run dev

## Fluxo

Upload DOCX -> Backend -> Conversão com LibreOffice -> Retorna PDF -> Download

## Funcionalidades

- Upload de arquivo
- Conversão automática
- Download do PDF
